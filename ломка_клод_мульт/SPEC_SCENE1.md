# Сцена 1 «Хук и смерть романтики» (0:00–0:35) — общий контракт

Мульт «Пять часов без мозгов». Вертикаль 1080×1920, 24 fps, сцена ≈ 35 с (~840 кадров, точная длина берётся из timing.json).
Сценарий: `script/pyat_chasov_bez_mozgov.txt` (СЦЕНА 1). Проект Remotion: `video/` (remotion 4.0.544, React 19, TS).

## Стиль: «бумажная аппликация» (cut-out, как в классических ТВ-мультах про городок в снегах)
Только вдохновение стилем — персонажи, лицо, одежда, дизайн ОРИГИНАЛЬНЫЕ, без копирования чужих героев/логотипов.
- Плоские фигуры из «цветной бумаги»: круглые головы, огромные белые круги-глаза с маленькими чёрными точками-зрачками, рот — чёрная форма, которая «хлопает» при речи, руки-варежки, тела — простые формы, ног почти нет, ходят скольжением.
- Лёгкая бумажная фактура: тонкий тёмный контур-тень (`filter: drop-shadow(1px 2px 0 rgba(0,0,0,.35))`), SVG feTurbulence-зерно поверх (общий оверлей делает интегратор, вам не надо).
- Анимация «картонная»: повороты шарниров, подскоки, сквош/стретч, никакого плавного ригa. Но движения живые: дыхание, моргание, мелкая мимика, overshoot (spring).
- Палитра общая (используйте как есть):
  `bg #1b1210 (тёмный тёплый), wall #8a5a3c, wallDark #5e3a27, floor #3b2a22, table #a9713f, tableDark #7a4c27, candleFlame #ffb43a, wax #f4ead2, skin #f1c9a0, skinShade #d9a97c, artyomHoodie #6b7280, artyomHair #2b1d16, katyaHair #a8431f, katyaDress #7a1f3d, ink #120c0a, white #ffffff, danger #e11d2a, uiBlue #3b82f6`.
- Вся графика — React + inline SVG (без внешних картинок/шрифтов, кроме системных). Любой код детерминирован от `useCurrentFrame()` (никакого Math.random без seed, CSS-анимаций, setTimeout).
- Шрифт текста на экране: `fontFamily: "Arial Black, Impact, sans-serif"`.

## Координаты
Мировое пространство сцены — "холст" 1080×1920 px; камера (интегратор) двигает/масштабирует/вращает обёртку. Все ваши компоненты рисуют в своих локальных координатах и принимают `x,y,scale,rotate` (px, множитель, градусы) — позиционирует интегратор через обёртку `<g>`/`<div>`. Компонент возвращает `<svg>` с viewBox, если не сказано иначе.

## Интерфейсы

### Characters (`import { Artyom, Katya } from "./characters"`)
Оба — React-компоненты, возвращающие `<svg width={w} height={h}>` (по умолчанию 1000×1400 viewBox, голова сверху, центр по X), пропсы:
```ts
type CharacterProps = {
  frame: number;                 // локальный кадр сцены (для дыхания/морганий; передаёт интегратор)
  view: "front" | "side";        // front — анфас (крупные планы); side — профиль (общий план за столом)
  facing?: "left" | "right";     // только для side
  mouth: number;                 // 0..1 — открытие рта (из аудио/таймингов, хлопание челюсти)
  emotion: "neutral" | "smile" | "teary" | "worried" | "panic" | "rage" | "dead"; // dead — лицо без жизни, глаза-пустышки
  look?: { x: number; y: number };      // направление взгляда зрачков, -1..1
  blink?: boolean;               // принудительное моргание (иначе авто по frame)
  armL?: ArmPose; armR?: ArmPose; // "rest" | "table" | "holdHand" | "underTable" | "typing" | "pointing" | "handsOnHead" | "slap"
  twitch?: number;               // 0..1 — нервный тик левого глаза/щеки (Артём в конце сцены)
  sweat?: number;                // 0..1 капли пота
  tear?: number;                 // 0..1 слеза (Катя)
  upperBodyOnly?: boolean;       // true — рисовать до пояса/стола (сидит за столом, для крупных планов обрезка)
  x?: number; y?: number; scale?: number; rotate?: number;
};
```
- **Артём**, 28: растрёпанный тёмный чуб, лёгкая щетина, серая толстовка с капюшоном, нелепо-серьёзное лицо, большие брови (хорошо читаются эмоции). Сидит за столом.
- **Катя**, 26: рыжевато-каштановое каре, бордовое платье с вырезом, серьги, «загадочная» полуулыбка в neutral, на smile/teary — растроганное лицо с блестящими глазами.
- Рот при `mouth` > 0.05 открывается (овал/D-форма, видны зубы/язык при >0.5); при emotion rage — зубы сжаты, широкий. Должно быть видно, что `mouth` меняется покадрово.
- Экспортировать также `ARTYOM_COLORS`, `KATYA_COLORS` не нужно — палитра общая.

### Set (`import { Kitchen, Candles } from "./set"`)
- `<Kitchen frame view />` — фон кухни целиком 1080×1920 (+ запас 20% по краям для движений камеры, т.е. viewBox -108 -192 1296 2304): тёплая стена, окно с ночным городом, холодильник, плита, полка, стол по центру (скатерть, две тарелки, бокалы, бутылка), пол. `view`: `"wide"` (боком, стол горизонтально по центру) | `"table"` (стол крупнее, вид сверху-спереди) | `"backWall"` (только стена+окно+свечи для заставки). Параллакс-слои: компонент принимает `parallax?: {x:number;y:number}` (−1..1) и сдвигает слои с разной глубиной.
- `<Candles frame x y scale melt? />` — свечи с мерцающим пламенем (детерминированное мерцание от frame), `melt` 0..1 — стекающий воск; `dropFrame?: number` — кадр, когда капля воска падает со свечи (анимация падения + мелкий всплеск).
- Свет: мягкое тёплое «свечное» свечение (радиальный градиент, mix-blend-mode: screen).

### Overlays (`import { PhoneScreen, UsageLimit } from "./overlays"`)
- `<PhoneScreen frame startFrame text sendFrame />`: вид «POV экрана телефона под столом» 1080×1920: тёмный экран, коричневая рука-силуэт по краю, UI мессенджера/Claude-подобный (НЕ копируй логотип — просто «ассистент» с оранжевой звёздочкой/искрой нейтрального вида), поле ввода, голосовой ввод (пульсирующий микрофон), печатающийся текст `text` (посимвольно, 28 симв/с от startFrame), кнопка «send»; на `sendFrame` нажимается и уходит «сообщение» вверх.
  Текст по умолчанию: «Клод блядь срочно придумай вежливую отмазку почему ее жирная токсичная мамаша не должна переступать порог моей хаты иначе я выйду в окно»
- `<UsageLimit frame startFrame />`: красная плашка с белым текстом «You've reached your usage limit. Please try again in 4 hours 59 minutes», вылетает с пружиной + дрожь; мигающая иконка предупреждения; поверх экрана телефона (1080×1920, плашка в середине). Также режим `compact` для маленького экрана.

### Audio (`video/src/scene1/timing.json`)
```jsonc
{
  "fps": 24,
  "durationSec": 35.0,                // итоговая длина сцены (по реальным репликам + паузы, укладываться в 33–37 с)
  "master": "audio/scene1/scene1_master.wav", // путь относительно video/public
  "lines": [
    { "id": "a1", "who": "artyom", "text": "...", "startSec": 3.2, "endSec": 14.1,
      "mouth": [0.0, 0.6, 0.9, ...] }   // огибающая громкости ~ 24 значения/с (0..1), для хлопания рта
  ],
  "cues": [ { "id": "zap", "sec": 20.4 }, { "id": "violinStop", "sec": 20.4 },
            { "id": "limitAppears", "sec": 20.6 }, { "id": "waxDrop", "sec": 33.0 } ]
}
```
Реплики сцены (ID → кто → подача):
- `a1` Артём (читает с экрана бархатным поставленным голосом): «Катюш, понимаешь… наши отношения — это не просто быт. Это, блядь, симфония двух несовершенных душ, где каждая твоя истерика — лишь крещендо нашей общей любви…»
- `k1` Катя (растроганная, всхлипывает, голос дрожит): «Господи, Тём… Ты такой глубокий. Ни один парень мне такого не говорил. А что ты думаешь насчет моей мамы, которая хочет переехать к нам на месяц?»
- `a2` Артём (глуповатая улыбка, нервно): «Секунду, любимая, дай мне… э-э… пропустить эту мысль через призму сердца.»
- `a3` Артём (шёпотом, лихорадочно, голосовой ввод): «Клод, блядь, срочно придумай вежливую отмазку, почему её жирная токсичная мамаша не должна переступать порог моей хаты, иначе я выйду в окно.»
- (zap + обрыв скрипки + плашка — только звук/музыка)
- `k2` Катя (удивлённо, растерянно): «Тём? Ты чего завис? Так что насчёт мамы?»
- `a4` Артём (сглатывает, затем хриплый первобытный голос без фильтров, срыв на крик): «Кать… Да пошла она нахуй, твоя мама! Она жрёт как комбайн, воняет корвалолом и в прошлый раз смыла в мой унитаз кошачий наполнитель!»
- затем ~2.5 с ТИШИНЫ с каплей воска.
Музыка: романтическая скрипка (синтез, мягкая, лёгкий вибрато), обрывается на zap визгом; потом тишина (комнатный тон). SFX: щелчки клавиатуры телефона, мерзкий звук короткого замыкания, визг скрипки, дрожь плашки (глитч), капля воска (тихий «плип»), шипение свечи, лёгкий скрип стула.
Мастер: моно/стерео 48 кГц WAV, пик ≤ −1 dBFS, голоса громче музыки.
