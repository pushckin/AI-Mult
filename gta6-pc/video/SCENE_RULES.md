# Правила для авторов сцен (whiteboard, 1920×1080)

Движок: `engine.js` (объект `E`), общий набор персонажей `kit.js` (объект `K`: `K.face(cx,cy,r,expr)` с expr: smile/big/scared/sad/happy/closed/cool/angry; `K.man`, `K.mark(type,x,y,s,c)` — check/arrow/star/... , `K.dot`), тайминги `timing.js` (объект `G`).
Образец стиля и API — прошлый ролик про АЭС: `/tmp/claude-0/ref/video/scenes_aes.js`, `/tmp/claude-0/ref/video/kit_aes.js` (только читать).

## Каркас сцены
```js
(function () {
  const { R, S, C, clamp, el } = E, { P } = G;
  const s = G.mk(N);            // N = номер сцены - 1
  s.d(shape, at, dur, tf)       // нарисовать фигуру маркером (dash-анимация + кончик маркера); tf — transform-строка, P(x,y,scale,rot)
  s.txt(str, at, dur, x, y, size, color, {anchor:'middle', rot})  // рукописный текст (Neucha, кириллица ок)
  s.bub(text, at, cx, cy, tailX, tailY, {maxW, fs})               // облачко pop-in, хвост указывает на (tailX,tailY); само добавляет звук pop
  s.show(shape, at, {origin:[x,y]})   // фигура целиком появляется пружиной
  s.anim(at, end, build(g), fn(lt, g)) // произвольная анимация (движение, пресс, мигание, огонь)
  s.sfx(name, at, vol)          // звуковое событие
  // у результата s.d(...) можно задать .dyn = lt => 'transform' — покачивание/движение уже нарисованной фигуры
})();
```
Фигуры: `R.line/rect/ell/circ/poly/curve/lin/path/arc` (Rough.js), склеиваются `S(a,b,...)`. Опции: `{c: цвет контура, w: толщина, fill: цвет, fs:'solid'|'hachure', gap, fw, r: шероховатость}`.

## Время
- Все `at`/`dur` — в НОМИНАЛЬНЫХ секундах сцены по сценарию (с 0 от начала сцены). Длительности: s1=15, s2=35, s3=35, s4=30, s5=35, s6=35, s7=15. Потом всё равномерно растянется под реальную озвучку.
- Последние 1.8 с сцены — губка-переход (её делает движок сам). Всё содержимое должно быть показано к `NOM - 2.5`.
- Рисование должно идти вровень с текстом диктора из сценария (что диктор называет — то и рисуется в этот момент), но без пустых пауз: доска «живёт» до самой губки (покачивания, мигание, огонь, разряды).

## Палитра
`C.ink #1A1A1A`, `C.blue #0077CC`, `C.red #E63946`, `C.orange #F77F00`, `C.green #2A9D8F` — основные. Доп.: `C.yellow, C.gray, C.skin, C.ltblue, C.ltgreen, C.ltred, C.white, C.brown`.

## Вёрстка
- Безопасная зона: x 60..1860, y 60..1030. Текст не должен выходить за края, облачка не должны перекрывать лица/важные рисунки и друг друга.
- Облачка: fs 38–46, maxW 380–520. Хвост — к говорящему персонажу.
- Никаких логотипов реальных брендов: названия только текстом от руки (PS5, Xbox, YouTube — надпись или простой значок-треугольник «play»).

## Проверка
Контрольный кадр: `node render.mjs shot <номер сцены> <номинальная секунда> checks/sN_<сек>.png` (можно несколько троек подряд). Смотреть PNG через Read. Делай 3–4 кадра на сцену (середина рисования, момент с облачками, перед губкой) и исправляй: обрезанный текст, наложения, кривые пропорции, пустоты.
