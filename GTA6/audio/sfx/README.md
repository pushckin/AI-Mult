# SFX — «Вторжение в Новую Зеландию» (GTA 6)

Все звуки сгенерированы процедурно скриптом `node sfx.mjs` (можно перегенерировать выборочно: `node sfx.mjs alarm punch`).
Формат: WAV 44100 Гц, моно, 16 бит, пик ≈ −1 dBFS (петли-амбиенсы тише: −3…−4.5 dBFS). «петля» — бесшовно зацикливается.
