# SFX — звук эффектов «Отряд Мега» (`kit/sfx.js`)

Весь звук синтезируется Web Audio из контекста, который передан в `__sound` (живой или `OfflineAudioContext` рендерера). Файлов нет. Шум — из буферов с зерном, результат повторяем. Голоса сюда НЕ входят — их накладывает сборщик.

## Подключение

```html
<script src="../kit/lines.js"></script>
<script src="../kit/sfx.js"></script>
<script>
window.__sound = (ctx, t0) => {
  const T = window.TIMING[3], B = T.beats;                     // сцена 3
  const s = SFX.init(ctx, t0, { partStart: T.partStart, room: 'field' });
  s.ambience('field', 0, T.duration);                           // фон на всю сцену
  s.duckLines(T.lines);                                         // приглушить фон под реплики
  s.footsteps(0.1, 1.5, { surface: 'dirt', rate: 2 });
  s.mortarThump(B.shell.t + 0.1, { pan: -0.5 });
  s.music('tender', B.shell.t + 0.4, B.impact.t, { fadeOut: 0.2 });
  s.cashRustle(B.shell.t + 2.0, { pan: 0.4 });
  s.shellWhistle(B.impact.t - 1.4, 1.4, { pan: 0.2 });          // свист кончается НА кадре взрыва
  s.explosion(B.impact.t, { size: 'big', pan: 0.2 });
  s.coin(B.impact.t + 1.6); s.pencil(16.0, 0.8, { pan: -0.3 });
  s.fadeOut(T.duration - 0.5, 0.5);                             // звук уходит вместе с картинкой
};
</script>
```

Кнопка «Старт»: `const ac = new AudioContext(); window.__sound(ac, ac.currentTime + 0.05); tl.play(0);`

## Правила

- Все времена — **секунды от начала своей сцены**. Звук ставь на кадр события (касание, склейка).
- `SFX.init(ctx, t0, opts)` вызывай **один раз** в `__sound`. `opts`: `partStart` (старт сцены в ролике — обязателен: от него сетка долей музыки и зёрна вариантов), `room: 'bunker' | 'cabin' | 'field'` (отзвук: сцена 1 — bunker, 2 — cabin, 3–5 — field), необязательные множители `master`, `fx`, `amb`, `mus`, `reverb`.
- У каждого метода общие опции: `pan` (−1…1), `gain` (множитель, 1 = как в таблице), `variant` (0…3 — принудительный вариант). Без `variant` зерно берётся из времени события, поэтому повторы звучат по-разному, а рендер повторяем.
- Уровни уже выставлены под голос −17 LUFS: не поднимай `gain` выше 1.5 без нужды. Если что-то «говорит поверх голоса» — опусти `gain` этого звука, а не всё сразу.
- На репликах зови `s.duckLines(TIMING[N].lines)`: музыка и атмосфера опускаются на 8 дБ, эффекты на 3 дБ.
- В конце сцены — `s.fadeOut(t, dur)`, иначе хвост эха обрежется склейкой.
- Не ставь два громких удара ближе 0,12 с, если это не задуманный слой (дверь + хруст — можно).

## Методы

Пик — замер одиночного звука после мастер-шины (dBFS), `gain: 1`.

| Метод | Что звучит | Рекомендации | Пик |
|---|---|---|---|
| `shot(t, {dist, pan})` | выстрел: щелчок механики, хлопок, низ 80–200 Гц, хвост-эхо | `dist: 'near'` — свой боец в кадре, `'mid'` — враг в кадре, `'far'` — из-за кадра (глухой «пок» с отражением) | −7 / −8,5 / −14 |
| `burst(t, n, {rate, dist, pan})` | очередь с неровным темпом; возвращает время конца | `rate` 9–11, `n` 3–6; разные `pan` у разных стрелков | −6 |
| `ricochet(t)` | щелчок + шумовой «виу» (не синус) | редко: 1–2 на перестрелку | −15 |
| `bulletDirt(t)` | тупой шлепок + песок | на кадр пыльного фонтанчика | −12 |
| `emptyClick(t)` | сухой тихий металлический щелчок | сцена 5, бит `silence`: 3–5 штук с разным `pan` | −19 |
| `explosion(t, {size, dist})` | фронт, удар 64→36 Гц, шумовая волна (фильтр вниз 1,7 с), осыпь, тихий звон | `size: 'big'` — один раз (сцена 3); `'small'` — мелкие; `dist: 'far'` — за холмом; `ring: false` убирает звон | −4 / −7 / −9 |
| `mortarThump(t)` | «тумп» + полый резонанс трубы + выдох дыма | на кадр выстрела миномёта | −7 |
| `shellWhistle(t, dur)` | падающий свист (шум через резонанс 2500→880 Гц), нарастает | `dur` 1,2–1,8; конец = кадр взрыва | −15 |
| `shellFlyBy(t, dur, {from, to})` | пролёт с доплером и панорамой | `dur` 0,8–1,4 | −12 |
| `doorSlam(t)` | стальная дверь: удар, низ, моды полотна, дребезг засова | сразу за ней `crunch(t + 0.03)` | −5 |
| `crunch(t)` | «хруп»: пачка щелчков + низкий шлепок | комично, не мерзко; после — такт тишины | −8 |
| `thud(t)` | мягкий удар с низом | падение предмета, каски | −10 |
| `bodyFall(t, {weight})` | удар тела, шорох формы, звяк снаряжения | `weight`: `'light'` / `'heavy'` / 0…1; `gear: false` — без звяка | −8,5 / −10,5 |
| `footsteps(t0, t1, {surface, rate})` | шаги | `surface: 'concrete'` (бункер) / `'dirt'`; `rate` 1,8–2,2 шага/с; одиночный — `step(t, {surface})` | −20 |
| `cloth(t)` | шорох ткани | взмах руки, поворот | −26 |
| `paper(t)` | шелест бланка | на кадр, когда лист в руке | −24 |
| `pencil(t, dur)` | карандаш пишет штрихами | `dur` 0,5–1,0 | −25 |
| `stamp(t)` | деревянный «тук» + пружинка | на кадр касания | −14 |
| `spoon(t)` | ложка о миску | 3–5 за сцену, разный `pan` | −21 |
| `zap(t)` | сухой треск статики | после `rubHands` | −13 |
| `rubHands(t, dur)` | трение ладоней | `dur` 0,5–0,9 | −25 |
| `cashRustle(t, {n})` | отсчёт купюр | `n` 4–6 | −23 |
| `coin(t)` | монета с отскоком | — | −23 |
| `terminalBeep(t)` | мягкий двухтональный сигнал | единственный электронный звук; один раз | −23 |
| `wireTwang(t)` | проволока: зацеп, негармоничные обертоны, шипы | бит `reveal` сцены 4 | −17 |
| `hammer(t)` | удар молотка по столбу | 2–3 подряд с шагом 0,4 с | −13 |
| `whoosh(t, dur, {panTo})` | мягкий свист движения камеры | длина = длина движения; ≤ 0,9 с | −23 |
| `dustPuff(t, {big})` | «пфф» пыли | после падений и двери | −22 |
| `heli(t0, t1, {inside, rpmFrom, rpmTo, ramp})` | лопасти + турбина; `inside` — глуше, с вибрацией | обороты винта: 300 = 20 Гц лопастей; взлёт `rpmFrom: 180, rpmTo: 320, ramp: 2.5`; под диалог `gain: 0.6` | RMS −27 / −29 |
| `heliLand(t)` | жёсткая посадка: удар, подскок, скрип, пыль | на кадр касания | −8 |
| `ambience(kind, t0, t1)` | `'bunker'` вентиляция и лампа · `'cabin'` гул кабины · `'field'` ветер, сверчки, редкая птица · `'zone'` ветер и далёкая канонада · `'aftermath'` тлеющая тишина | одна на сцену; `fadeIn`/`fadeOut`; `crickets: false`, `birds: false` | RMS −39…−44 |
| `music('march', t0, t1)` | вялый марш: туба + малый барабан, 92 уд/мин | сцены 1, 2, 4; выключай перед паузой-шуткой (`fadeOut: 1`) | RMS −31 |
| `music('tender', t0, t1)` | музыкальная шкатулка, вальс 126 уд/мин | полёт снаряда в сцене 3; обрывай на взрыве (`fadeOut: 0.2`) | RMS −34 |
| `music('fanfareSad', t)` | кривая фанфара, 2,9 с: верхняя нота не дотянута и оседает | титр «ПОБЕДА» | −13 |
| `sting(t, {variant})` | пиццикато-акцент, 4 варианта | после такта тишины за шуткой; не чаще раза в 5 с | −16 |
| `duck(t0, t1, дБ)` | приглушить фон (по умолчанию 8 дБ; эффекты — 40 % от этого) | `{fx: 0}` — не трогать эффекты | — |
| `duckLines(lines, дБ)` | то же по массиву реплик (`t`, `dur`); близкие реплики сливаются | `s.duckLines(TIMING[N].lines)` | — |
| `fadeIn(t, dur)` / `fadeOut(t, dur)` | общий вход/выход звука сцены | конец каждой сцены | — |

Свой звук: `s.noise(t, {n:'w'|'p'|'b', fl:[{t:'bandpass', f, f1, q}], a, tau, dur, g, pan, rev})` и `s.tone(t, {f, f1, a, tau, dur, g})` — шумовой и тональный голос с огибающей, доведённой до нуля.

## Где что в сценах

| Сцена | room | Атмосфера | Музыка | Ключевые звуки |
|---|---|---|---|---|
| 1 база | `bunker` | `bunker` | `march` до бита `stare` | `spoon`, `paper` ×4, `footsteps` concrete, `doorSlam` + `crunch` + `dustPuff`, `pencil`, `rubHands`, `stamp` |
| 2 вертолёт | `cabin` | `cabin` | `march` тихо (`gain: 0.7`) | `heli` inside (взлёт: рост оборотов), `heliLand`, `dustPuff` big, `cashRustle`, снаружи — `heli` без `inside` |
| 3 поле | `field` | `field` | `tender` на бит `shell` | `footsteps` dirt, `mortarThump`, `shellWhistle`, `explosion` big, `thud` (каска), `cashRustle`, `pencil` |
| 4 зона | `field` | `zone` | `march` до бита `firefight` | `wireTwang`, `hammer`, `burst`/`shot` трёх дальностей, `bulletDirt`, `ricochet`, `bodyFall` разного веса, `rubHands` → `zap`, `stamp` |
| 5 финал | `field` | `aftermath` | `fanfareSad` на `victory` | `emptyClick`, `terminalBeep`, `footsteps`, `doorSlam` + `crunch` на `black`, `sting` |

## Проверка

`node tools/render-sfx.cjs [showcase firefight mortar scene1]` рендерит демо из `kit/demo-sfx.html` в `out/sfx/*.wav`, пишет замеры (`*.txt`) и спектрограммы (`*.png`). Сама страница `kit/demo-sfx.html` — кнопки для прослушивания каждого звука.

Спектрограммы ffmpeg делай с высотой, равной степени двойки (`s=1600x512`): при другой высоте `showspectrumpic` с `fscale=log` рисует ложную яркую полосу посередине.
