# RIG — персонажи с суставами и физикой (`kit/rig.js`)

Пять персонажей: `ustav`, `chaika`, `ladoshka`, `hohotun`, `gvozd`. Рост ≈ 600 px при `scale: 1`. Всё детерминировано: работает при `tl.seek(t)` в любую сторону (нет setTimeout/rAF/random).

## Подключение
```html
<script src="vendor/gsap.min.js"></script>
<script src="rig.js"></script>
<script>
  var tl = gsap.timeline({paused:true}); window.__timelines = {main: tl};
  var u = Rig.create('ustav', {x:300, y:1200, scale:0.8, parent: sceneDiv});
  u.idle(tl, 0, 10); u.blinks(tl, 0, 10);
  u.talk(tl, 1, 3);                       // 3 с говорит
  var t = u.walkTo(tl, 4.5, 800, 3);      // вернёт время окончания (7.5)
  u.fall(tl, t + 0.5, {style:'knees', dir:1});
</script>
```

## Создание
`Rig.create(name, {x, y, scale, facing, parent})` — возвращает персонажа.
- `x, y` — точка на земле между стопами (px сцены), `scale` — 1 = 600 px.
- `facing`: -1…1, 0 = анфас, ±0.85 = полуповорот вправо/влево (лучше для ходьбы).
- `parent` — DOM-узел сцены (абсолютно позиционированный блок). `ch.el` — корневой `<svg>` (overflow visible), его можно вставить и позже: `scene.appendChild(ch.el)`. Положение персонажа задаётся не CSS, а моделью (`ch.set({x:..,y:..})` до таймлайна; в таймлайне двигают `walkTo`/`ch.to`).
- `ch.hand('L'|'R')` — SVG-узел `<g>` кисти: `ch.hand('R').appendChild(prop)`; реквизит едет и вращается с рукой. Есть `ch.give(node, side, {x,y,rot,scale})`, `ch.take(side)`, встроенный реквизит `ch.prop(tl,t,side,'notebook'|'pencil'|'bowl'|'spoon', on)`. `Rig.prop(name)` — узел реквизита.
- `Rig.names`, `Rig.poses`, `Rig.falls`, `Rig.fallInfo(style)` → `{total, main}`.

## Методы
Каждый добавляет твины в `tl` и **возвращает время окончания** (сек). `t` — время старта.

| Метод | Что делает |
|---|---|
| `idle(tl,t0,t1)` | дыхание, перенос веса (у каждого свой ритм), лёгкие покачивания убора. Можно накладывать на позы/речь |
| `blinks(tl,t0,t1)` | моргание (случайные, но с зерном) |
| `talk(tl,t,dur,{energy,hand,gesture})` | липсинк 8–10 форм/с, кивки, жест рукой (`gesture:false` — без жеста), в конце рот закрыт. `energy` 0.5…1.5 |
| `mouth(tl,t,shape)` | форма рта вручную: 0 покой/закрыт, 1 «А», 2 «О», 3 улыбка (у Гвоздя/Хохотуна — своя), 4 сжат, 5 малое открытие |
| `look(tl,t,dx,dy,dur=0.35)` | взгляд: dx,dy −1…1; зрачки → голова → корпус догоняет |
| `turn(tl,t,facing,dur=0.4)` | поворот корпуса/головы (−1…1) |
| `pose(tl,t,name,dur=0.4)` | поза (список ниже), переход 0.3–0.7 с, с предвосхищением и запаздыванием рук |
| `walkTo(tl,t,x,dur,{stride,face})` | ходьба до x с шагами (контакт стоп, качание таза, противоход рук, наклон на разгоне/торможении). `dur` по умолчанию ≈ 0.33 с на шаг. Корень ≤ ~25 px/кадр при шаге ≥ 0.4 с |
| `bounce(tl,t,amp=30)` | подброс от тряски, ~0.5 с |
| `flinch(tl,t,{amp,dir})` | вздрогнуть, ~0.5 с |
| `jump(tl,t,h=120)` | прыжок с приседом, ~0.9 с |
| `squash(tl,t,{axis:'y'|'x',to,hold})` | пружинное сплющивание (дверь): ударяет за 0.2 с, держит `hold` (0.6), вылезает упруго. `hold:Infinity` — остаться плоским |
| `fall(tl,t,{style,dir,jitter,seed})` | падение, см. ниже |
| `getUp(tl,t,dur=2.4)` | оживание: рывок как от разряда → садится → трясёт головой → встаёт, глаза нормальные |
| `loop(tl,name,t0,t1)` | цикличная поза `rubHands`/`write`/`eat`/`wave` на отрезке t0…t1 (то же, что `pose(tl,t0,name,t1-t0)`); возвращает t1 |

## Позы
`stand, sit, salute, point, shrug, think, handOut, rubHands, write, eat, cower, facepalm, wave, hold, cheerWeak` (лёжа слабо поднимает руку — вызывать после падения). `point`, `wave` и пр. зеркалятся сами, если персонаж повёрнут влево. `sit` опускает таз ровно на высоту ящика ≈ 56 px (scale 1) — поставьте персонажа так, чтобы стопы стояли на земле, а ящик под тазом рисуйте на уровне y−56·scale.

## Падения: `dir` = +1 вправо, −1 влево; длительности `total` (включая остаточное движение)
- `knees` (2.7 с, основное 1.6) — колени подкашиваются, оседает, заваливается набок, голова догоняет и чуть отскакивает.
- `back` (2.5 / 1.3) — отбросило назад, руки взлетают, ноги вверх и падают, убор слетает.
- `face` (2.6 / 1.4) — ничком: колени, корпус, лицо, отскок попы, убор катится.
- `spin` (2.8 / 1.9) — провернуло вокруг оси и сложило.
- `sit` (3.4 / 3.0) — сел на попу, посидел в шоке, медленно лёг набок.
- `blast` (3.0 / 1.9) — взрывная волна: дуга по воздуху с вращением, два отскока, скольжение, убор улетает.
После падения: глаза-крестики, тень растягивается, нога подёргивается, убор доезжает. После `fall` можно `pose(…,'cheerWeak')`, потом `getUp`.

## Ограничения (важно)
- Один канал — один твин: не вешайте на персонажа два пересекающихся по времени `pose`/`walkTo`/`fall`. `idle`, `blinks`, `talk`, `look` — отдельные слои, их можно совмещать с позой. Не вызывайте `idle` поверх `fall`/`walkTo`/`getUp` (закончите idle до них и начните после).
- Двигать `ch.el` через gsap нельзя — положение живёт в модели (`ch.m.x/y`): используйте `walkTo` или `ch.to(tl,t,{x:..},dur)`.
- `ch.set(vars)` — только до таймлайна (мгновенно). `ch.to(tl,t,vars,dur,ease)` — прямой твин каналов модели.
- Только фронтальный / полупрофильный вид; поворот на 180° нет (`spin` показывает тонкий силуэт в середине вращения).
- Порядок вызовов по времени вперёд: следующий метод читает состояние «после предыдущего».
- За кадр (1/30 с) сегмент поворачивается ~≤30° (пики до ~50° на рывках рук в getUp/blast), корень ≤ ~25 px (blast до ~35 px).
- Падение смещает персонажа по земле (до ~250 px по `dir`) — оставьте место.

## Пример (≈10 строк)
```js
var g = Rig.create('gvozd', {x:200, y:1250, parent:scene, facing:0.85});
g.idle(tl, 0, 2);
var t = g.walkTo(tl, 2, 760, 3.2);          // идёт к двери
g.look(tl, t, 1, 0, 0.3);
g.squash(tl, t + 0.4, {axis:'y', hold:1.0}); // дверь захлопнулась
var u = Rig.create('ustav', {x:850, y:1250, parent:scene});
u.pose(tl, 1, 'write', 3); u.talk(tl, 4.6, 0.5);
u.fall(tl, 6, {style:'blast', dir:-1});
u.getUp(tl, 9.5, 2.4);
```
